# 图片压缩工具

这是一个简单易用的在线图片压缩工具,采用纯前端实现,无需后端服务器。

## 功能特点

- 支持上传 PNG、JPG、WebP、GIF 等常见图片格式
- 支持自定义压缩比例
- 实时预览压缩前后的图片效果
- 显示压缩前后的文件大小
- 支持批量上传和下载
- 智能压缩算法，避免压缩后文件变大
- 支持深色模式
- 完整的键盘快捷键支持
- 优雅的压缩进度提示
- 采用苹果风格设计,界面简洁美观

### 图片编辑功能
- 裁剪：自由调整裁剪区域
- 旋转：90度旋转和自由角度旋转
- 翻转：水平和垂直翻转
- 调整大小：等比例缩放

## 技术栈

- HTML5 Canvas
- CSS3 
- JavaScript
- 使用 browser-image-compression 库实现图片压缩
- 使用 JSZip 实现批量下载

## 快捷键

- `Ctrl/Cmd + O`: 打开文件
- `Ctrl/Cmd + S`: 下载当前图片
- `Ctrl/Cmd + Shift + S`: 批量下载
- `←/→`: 切换上一张/下一张图片
- `Delete/Backspace`: 删除当前图片
- `Esc`: 关闭编辑对话框

## 页面结构

主页面分为以下几个部分:

1. 顶部标题区
2. 图片上传区
   - 拖拽上传区域
   - 文件选择按钮
3. 图片列表区
   - 显示所有上传的图片
   - 支持点击切换预览
4. 图片编辑区
   - 裁剪工具
   - 旋转工具
   - 翻转工具
   - 缩放工具
5. 压缩设置区
   - 压缩比例滑块
   - 实时压缩进度显示
6. 预览区
   - 原图预览
   - 压缩后预览
   - 文件大小信息
7. 下载区
   - 单图下载按钮
   - 批量下载按钮

## 使用说明

1. 点击上传区域或拖拽图片到上传区域
2. 使用编辑工具调整图片（可选）
3. 通过滑块调节压缩比例
4. 在预览区查看压缩效果
5. 使用快捷键或按钮下载压缩后的图片

## 浏览器兼容性

## 深色模式

工具支持自动跟随系统的深色模式设置，提供更好的夜间使用体验。

## 性能优化

- 使用 Web Worker 进行图片压缩
- 智能压缩算法，根据图片大小自动调整策略
- Canvas 优化，避免内存泄漏
- 优化的移动端适配
- 延迟加载和防抖处理
